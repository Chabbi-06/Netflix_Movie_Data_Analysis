# Netflix_Movie_Data_Analysis
Netflix data analysis &amp; dashboard project using Python.

📌 Project Overview

This project focuses on analyzing a Netflix movie dataset to extract meaningful insights about genres, popularity, and release trends. The analysis is based on key business questions and is supported by an interactive dashboard.

🎯 Problem Statements

The project aims to answer the following questions:

What is the most frequent genre of movies released on Netflix?\n
Which genre has the highest number of votes?\n
Which movie has the highest popularity? What is its genre?\n
Which movie has the lowest popularity? What is its genre?\n
Which year has the highest number of movie releases?
